UPSC BEAST MODE — UPDATED INSTALLABLE WEB APP

Includes progress tracking by day, week, month and year, habit-level consistency, weekly breakdowns, editable habits, add/delete habit controls, study timer, exam countdown, reflections and JSON backup/restore.

INSTALL: Host all files in this folder on an HTTPS site (for example GitHub Pages). Open the HTTPS page in Chrome on Android, then use ⋮ → Install app / Add to Home screen. Opening index.html directly from Downloads does not enable PWA installation/offline caching.

DATA: Progress is stored in the browser on this device. Export backups regularly. This is a PWA, not a native APK.
